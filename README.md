# OpenPages – Digital Library

OpenPages is a multi-page static website that simulates a digital library experience. It allows users to browse books by genre, register as a member, and fill out a personalized reading preference form to receive recommendations.

Live Demo: https://madhushreerasal.github.io/OpenPages-Digital-Library/

# Features
- Home Page – Introduction to the platform with a clean hero section
- Registration Page – Member sign-up form with multiple input types (text, email, radio, file upload, etc.)
- Preference Form – Personalized questionnaire for book recommendations
- Books Page – Genre-based book layout (Fantasy, Sci-Fi, Thriller)
- Responsive layout structure (basic level)
- Multi-page navigation using HTML forms and links
- Icon integration using Remix Icons
